# Personal Portfolio Studio

冰蓝渐变风格的设计师作品集，内含可视化编辑器、原创 AI 概念视觉和在线内容后台。

## 本地运行

需要 Node.js 24，无第三方运行依赖。

```sh
npm start
```

打开终端显示端口对应的本机地址，默认端口为 3000。开发模式沿用现有管理密码；生产环境第一次启动必须通过托管平台的 `ADMIN_PASSWORD` 安全设置管理员密码，不能把值写入前端或提交到仓库。

可以复制 `.env.example` 为 `.env` 配置本机环境；`.env`、数据库和媒体目录均已忽略，不应提交。用 `npm test` 运行服务端集成测试。

## 在线功能

- 服务端密码验证、HttpOnly 会话 Cookie、CSRF 与来源校验。
- 登录后编辑所有原有文字、增删文字段落、技能和项目。
- 调整配色、留白、圆角、封面比例、作品列数、模块顺序及显示状态。
- 新增、修改、排序和删除子页面；在线路径为 `/p/页面路径`。
- 子页面支持单列、双列和图文混排，手机端自动单列。
- 上传图片、保留原始 GIF 动画、上传 MP4 / WebM；视频有手动播放控件。
- 线上保存立即更新服务端内容，其他设备刷新即可查看。
- SQLite 数据库与媒体文件保存在持久目录，服务重启后保留。
- 多个编辑窗口版本冲突时拒绝覆盖；可以先备份自己的修改，再刷新。
- 内容备份和展示快照会带上媒体，不依赖原站的临时文件地址。

“隐藏页面”控制展示和导航，不是私密文件保险箱。上传到作品集中的媒体按公开展示处理。联系表单仍为演示，不会发送邮件。

## 部署

详见 [部署上线指南](部署上线指南.md)。提供 `Dockerfile` 和 `render.yaml`，可部署到支持持久磁盘的 Docker 托管平台或自有服务器。不要将这个在线后台部署为只有静态文件的 GitHub Pages 服务。

当前没有已发布的公网域名。Render 等平台会在服务创建成功后提供实际子域名，再按其显示的 DNS 设置绑定独立域名。账号注册与平台子域名可免费提供，服务器和持久存储按平台套餐计费；当前 Render 模板使用付费 Starter 实例及 1GB 持久磁盘，不是永久免费服务器方案。

## 环境配置

| 名称 | 用途 |
| --- | --- |
| `ADMIN_PASSWORD` | 首次生产启动所需的管理员密码；更改后会使旧会话失效。通过托管平台的安全设置填写。 |
| `DATA_DIR` | 数据和媒体目录，Docker / Render 中为 `/data`。必须挂载可写的持久磁盘。 |
| `PUBLIC_URL` | 最终 HTTPS 网站源地址，不含路径；Render 可自动使用 `RENDER_EXTERNAL_URL`。 |
| `PORT` | HTTP 服务端口，默认 3000，托管平台可覆盖。 |
| `MAX_UPLOAD_MB` | 单个媒体上传限制，默认 100MB。 |
| `NODE_ENV` | 生产使用 `production`，登录 Cookie 标记 Secure，需由 HTTPS 入口访问。 |

运行一个应用实例。SQLite 和本地媒体目录不适用于没有共享存储的多实例扩容。生产反向代理需把域名请求传到应用，网站外部使用 HTTPS。

## 数据与备份

持久目录包含 `portfolio.sqlite` 和 `uploads/`，二者都要备份。日常可通过编辑面板下载内容 JSON 备份，含已使用的媒体；导入后恢复全部子页面和作品。数据库或托管磁盘容量是有限的，应定期检查用量。

删除页面或移除媒体会立即取消展示。旧媒体文件保留在服务器中，便于既有备份恢复；不是立即清理磁盘的操作。如需回收磁盘，应先备份并核对文件引用。

## 静态文件模式

直接打开原始 `index.html` 时，仍能使用原有本地编辑模式。本地保存只在当前浏览器生效，不会同步线上网站。在线版导出的 HTML 是展示快照，管理操作应返回原站；不要用快照替换服务端项目文件。

本项目无构建步骤，Tailwind 通过 CDN 加载；生成图片已嵌入 HTML，不依赖外部图片目录。
